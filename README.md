# FitBuddy – AI Fitness Plan Generator

FitBuddy is an AI-powered fitness and wellness web application.

## Technologies

- Python
- FastAPI
- Jinja2
- SQLite
- SQLAlchemy
- Pydantic
- Google Gemini
- HTML
- CSS

## Features

1. User registration
2. Personalized 7-day workout plan
3. Nutrition/recovery tip
4. AI feedback-based plan update
5. SQLite database
6. Admin dashboard
7. REST API
8. Swagger API documentation
